# Вічна пам'ять — меморіальні сторінки захисників України

Статичний сайт на GitHub Pages. Кожному воїну — окрема сторінка з власним посиланням для QR-коду.

**Онлайн:** https://avikot.github.io/pamyat/

## Структура

```
pamyat/
├── index.html            # головна: список усіх воїнів
├── assets/style.css      # спільні стилі
├── serhii-ulitych/
│   ├── index.html        # сторінка воїна
│   └── photo.jpg         # фото (додати вручну)
└── .nojekyll
```

## Як додати фото

Поклади файл `photo.jpg` у папку воїна (напр. `serhii-ulitych/photo.jpg`).
Рекомендований портрет: вертикальний, ~800×1000 px. Якщо фото немає — покаже елегантний плейсхолдер.

## Як додати нового воїна

1. Скопіюй папку `serhii-ulitych/` під новим латинізованим ім'ям, напр. `ivan-petrenko/`.
2. Відредагуй `index.html` у ній: ім'я, дати, біографію, шлях, нагороди.
3. Додай картку до кореневого `index.html`.
4. Закоміть і запуш — сторінка оновиться автоматично.

## Релігійний символ (за бажанням)

За замовчуванням символу над іменем **немає** — воїни різних конфесій (православні,
протестанти, католики), а також мусульмани та невіруючі. Якщо родина воїна бажає символ,
додай рядок одразу перед `<h1 class="name">` на ЙОГО сторінці:

```html
<div class="mark">✝</div>   <!-- порожній латинський хрест: католики / протестанти -->
<div class="mark">☦</div>   <!-- православний хрест -->
<div class="mark">☪</div>   <!-- півмісяць: мусульмани -->
```

Стиль `.mark` уже є у `assets/style.css` — нічого більше налаштовувати не треба.

## Посилання для QR-коду

Кожна сторінка має власний URL, напр.:
`https://avikot.github.io/pamyat/serhii-ulitych/`
Згенеруй QR будь-яким генератором на цей URL.
